# popn_modernize_patcher

[English](README.md) | **日本語**

PS2 版 *pop'n music*（7〜14 FEVER! / BEST HITS）用の PCSX2 `.pnach` パッチを生成する GUI ツールです。
使いたい機能にチェックを入れ、必要な数値を入力すると、PCSX2 の `patches` フォルダに `.pnach` を書き出します。

## 機能

タイトルにより利用できる機能は異なります。

- ハイスピード拡張（x2〜x8 / x10、0.5 刻み。タイトルにより LOW あり）
- 判定タイミング調整
- 全モードで COOL 判定
- スコア計算式（現行 pop'n 方式）
- ゲージ MAX 時に FEVER にならない
- PERFECT = GOOD 0 かつ BAD 0
- キービーム長
- レーン明度
- COOL 判定幅 25ms
- 小節線 OFF
- 480p テスト（実験的）

内蔵パッチデータは、PCSX2 の patches フォルダにある既存の pnach を元にしています。
UI は日本語/英語に対応し、設定はプリセットとして保存できます。

## 使い方

1. Releases から OS に合った実行ファイル（Windows / macOS / Linux）をダウンロードするか、
   ソースから実行します（Python 3.8+、標準ライブラリのみ、tkinter が必要）。

   ```
   python popn_modernize_patcher.py
   ```

2. PCSX2 のデータフォルダ（`patches` と `gamesettings` の親フォルダ）を選択します。
3. タイトルを選び、機能にチェックを入れ、必要な数値を入力します。
4. 書き出しボタンを押すと `patches/<シリアル>_<CRC>.pnach` が作成されます。
5. PCSX2 側でパッチを有効にします（設定 → エミュレーション → チート/パッチを有効化）。

内蔵データの整合テスト:

```
python popn_modernize_patcher.py --selftest
```

オプション: プログラムと同じフォルダに `features_extra.json` を置くと、追加の機能定義として読み込まれます。

## ビルド

PyInstaller はクロスコンパイルできないため、各 OS 上で実行してください（CI: `.github/workflows/build.yml`）。

```
python build.py
```

成果物は `release/` に出力されます。

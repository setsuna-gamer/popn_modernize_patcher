# popn_modernize_patcher

[English](README.md) | **日本語**

PS2 版 *pop'n music*（7〜14 FEVER! / BEST HITS）用の PCSX2 `.pnach` パッチを生成する GUI ツールです。
使いたい機能にチェックを入れ、必要な数値を入力すると、PCSX2 の `patches` フォルダに `.pnach` を書き出します。

## 機能

タイトルにより利用できる機能は異なります。

- ハイスピード拡張（x1.5〜x8 / x10、0.5 刻み。タイトルにより LOW あり）
  - 追加オプション（ハイスピード拡張が有効なときだけ選択可）: オプション画面にハイスピードの実際の値を表示
- 判定タイミング調整
- 全モードで COOL 判定
- スコア計算式（現行 pop'n 方式）
- ゲージ MAX 時に FEVER にならない
- PERFECT = GOOD 0 かつ BAD 0
- キービーム長
- レーン明度
- COOL 判定幅 25ms
- 小節線 OFF（フリートレーニングモードで小節線を描画しない。8 のみ）
- オプション画面に BPM 表示（7 / BEST HITS。ハイスピード値表示とは独立）
- 480p 出力
- キャラ選択の初期キャラ変更（7 / 8 / 9 / BEST HITS。内蔵のキャラ表から選択、または16進IDを直接入力）
- タイトルからモード選択等を飛ばして FREE のミュージックセレクトへ直接遷移（全作品。初回のみ。作品によりキャラ選択・ボタン選択・SIDE 選択も飛ばす。BEST HITS で直接ミュージックセレクトへ遷移するには、ゲームの OPTION の SKIP 設定で CHARACTER SELECT と LINE SELECT を OFF にする）
  - 追加オプション（7 のみ。上記が有効なときだけ選択可）: タイトルメニュー(OPTION/GAME)も飛ばす

内蔵パッチデータは、PCSX2 の patches フォルダにある既存の pnach を元にしています。
UI は日本語/英語に対応し、設定はプリセットとして保存できます。

## 使い方

1. Releases から OS に合った実行ファイル（Windows / macOS / Linux）をダウンロードするか、
   ソースから実行します（Python 3.8+、標準ライブラリのみ、tkinter が必要）。

   ```
   python popn_modernize_patcher.py
   ```

2. PCSX2 のデータフォルダ（`patches` と `gamesettings` の親フォルダ）を選択します。
3. タイトルを選び、機能にチェックを入れ、必要な数値を入力します。
4. 書き出しボタンを押すと `patches/<シリアル>_<CRC>.pnach` が作成されます。
5. PCSX2 側でパッチを有効にします（設定 → エミュレーション → チート/パッチを有効化）。

補足:

- 同名の pnach が既にある場合、チェックしなかった機能のセクションは残し、それ以外を上書きします。
  元のファイルは `<名前>.bak_YYYYMMDDhhmmss` として退避されます（出力のたびに別ファイル。古いものは自動では削除されません）。
  「PCSX2 側のパッチも有効化する」を選んだ場合の `gamesettings/<シリアル>.ini` も同様です。
- BPM 表示・ハイスピード値表示・480p は、ステートのロードでは反映されません。ゲームを最初から起動してください。

内蔵データの整合テスト:

```
python popn_modernize_patcher.py --selftest
```

オプション: プログラムと同じフォルダに `features_extra.json` を置くと、追加の機能定義として読み込まれます。
同じ場所の `characters.json` でキャラ表を追加・上書きできます（内蔵の表は一部のみ）:
`{"SLPM-65316_18B64A1A": [{"id": "0x1B", "name": "BAMBOO"}]}`

## ビルド

PyInstaller はクロスコンパイルできないため、各 OS 上で実行してください（CI: `.github/workflows/build.yml`）。

```

```
